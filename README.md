# pyttsx3 テキスト音声変換ツール

Pythonライブラリのpyttsx3を使って、テキストから音声変換したファイルを出力するツールです。

## 特徴

- インストールされるツールの容量は100MB以下と軽量
- 入力テキストはテキストファイルを選択、テキストエリアに直接入力、フォルダ内にあるテキストを全て処理から選択可能
- 2時間以上にわたる長時間の音声合成も作成可能
- 専門用語変換用辞書テキストに単語の読み方を登録することで独自の読み方で音声変換できる
- 仮想環境を構築し実行するようbatファイルを同梱
- ローカル環境で実行

## 機能

- ブラウザベースの直感的なインターフェース
- 3つの入力方法：
  - テキストファイルのアップロード
  - テキストエリアへの直接入力
  - フォルダからの一括処理
- 専門用語の自動カタカナ変換
- 読み上げ速度の調整（4段階）
- 音声ファイルのダウンロード機能

## 環境
- Python 3.9以上（3.10.6で動作確認済み）
- Flask Webフレームワーク
- pyttsx3 音声合成ライブラリ
- ローカルホスト（localhost:5051）で実行

## セットアップ

1. 必要なパッケージをインストール：
install.batを実行

2. アプリケーションを起動：
run_app.batを実行

3. ブラウザで `http://localhost:5051` にアクセス

※2回目以降の実行は2以降を実行

## 使用方法

### 入力方法の選択

#### 1. テキストファイルを使用
- ファイル選択ボタンでテキストファイル（.txt, .md）を選択
- ファイルから変換開始ボタンでファイルの内容を読み込んで音声変換
- 音声ファイルをダウンロードボタンで保存ダウンロード

#### 2. テキストエリアに直接入力
- テキストエリアに直接テキストを入力
- リアルタイムで入力内容を確認
- 音声ファイルをダウンロードボタンで保存ダウンロード

#### 3. フォルダから入力
- `input/` フォルダ内のtxtファイルを一括処理
- 各ファイルの元のファイル名に基づいて出力ファイル名を自動生成
- `output/` フォルダに変換されたファイルを出力

### 読み上げ速度設定

4段階の読み上げ速度から選択：
- **デフォルト** (200 wpm)
- **すこしゆっくり** (170 wpm)
- **ゆっくり** (140 wpm)
- **かなりゆっくり** (100 wpm)

### 出力設定

- 出力ファイル名を指定（デフォルト: output.wav）
- 自動的に.wav拡張子が追加されます
- フォルダ処理の場合は出力ファイル名の指定は不要

### 処理フロー

#### テキストファイルを使用する場合
1. ファイル選択ボタンでテキストファイルを選択
2. ファイルの存在確認とサイズチェック
3. テキスト読み込み（UTF-8エンコーディング）
4. 専門用語変換処理
5. 音声変換処理
6. 音声ファイルをダウンロードボタンで保存ダウンロード

#### テキストエリアを使用する場合
1. テキストエリアにテキストを入力
2. 文字数制限チェック（最大100,000文字）
3. 専門用語変換処理
4. 音声変換処理
5. 音声ファイルをダウンロードボタンで保存ダウンロード

#### フォルダから入力する場合
1. `input/` フォルダ内のtxtファイルを自動検出
2. 各ファイルを順次処理
3. 専門用語変換処理
4. 音声変換処理
5. `output/` フォルダに保存
6. 処理結果を詳細表示

### 専門用語変換処理
そのままでは読み間違えられる単語を、前処理として指定のカタカナに変換する処理です。

`change_library.txt`を編集することで、専門用語を追加、変更できます。

例：
pyttsx3=パイティーティーエスエックススリー

## 制限事項

- **最大ファイルサイズ**: 500KB
- **最大文字数**: 100,000文字
- **対応ファイル形式**: .txt, .md
- **音声形式**: WAV
- **文字エンコーディング**: UTF-8

## 出力

### ファイル・テキスト入力の場合
変換された音声ファイル（.wav形式）が指定したファイル名でダウンロードされます。

### フォルダ入力の場合
`output/` フォルダに各ファイルの音声ファイルが保存されます。
- 元ファイル名: `sample.txt` → 出力ファイル名: `sample.wav`

## トラブルシューティング

### よくある問題

1. **インストールできない**
   - 管理者権限で実行してみてください
   - Python3.9以降をインストールしているか確認してみてください（3.10.6で動作確認済です）

2. **音声ファイルが生成されない**
   - システムの音声ドライバーが正しくインストールされているか確認
   - 管理者権限で実行してみてください

3. **ファイルアップロードエラー**
   - ファイルサイズが500KB以下か確認
   - 対応形式（.txt, .md）か確認
   - UTF-8エンコーディングで保存されているか確認

4. **フォルダ処理エラー**
   - `input/` フォルダが存在するか確認
   - フォルダ内にtxtファイルがあるか確認
   - ファイルがUTF-8エンコーディングで保存されているか確認

5. **change_library.txtを書き換えたのに反映されない**
   - 実行中のアプリなどを全て閉じ、起動しなおしてみてください

6. **文字数やファイルサイズの上限を変えたい**
   - app.pyのMAX_TEXT_LENGTHで最大文字数を、MAX_FILE_SIZEで最大ファイルサイズを変更できます
